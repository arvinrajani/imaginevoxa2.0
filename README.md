# Voxa — LinkedIn Content Studio

AI-powered LinkedIn content creation, image generation, brand management, and scheduling platform.

## Features

- 🤖 AI post generation with proven frameworks (AIDA, PAS, Story, Listicle)
- 🎨 Layer-based image editor with AI generation & brand-aware prompting
- 🏷️ Brand kit management with logo, colors, fonts, and tone
- 📅 Smart scheduling with AI-optimized posting times
- ✅ Compliance & quality checks before publishing
- 📊 ROI insights and performance tracking
- 🔗 Direct LinkedIn OAuth integration & auto-posting

## Quick Start

```bash
npm install
cp .env.example .env.local   # fill in your keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
